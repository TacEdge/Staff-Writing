# Reference and validation material

Fixtures exist for every implemented template (`fixtures/<template>/`); DFI
examples are re-keyed where the DFI provides one. `dfi-pages/` is regenerated by
`python -m staffwriting.compare` and is git-ignored.

| Folder | Content |
|---|---|
| `dfi-pages/` | PNG renders of DFI template and example pages (from `source/dfi-5.1/dfi_5_1.pdf` via `pdftoppm`). Regenerable; may be git-ignored if they become large. |
| `fixtures/<doc-type>/` | DFI example annexes re-keyed as content files, plus the expected lint results. Used to render and visually compare against `dfi-pages/`. |

Content rules: fictional or DFI-supplied content only. No real correspondence,
personal information or protectively marked material.
