# Template inventory: DFI 5.1 v2.01

This lists every formal document type for which DFI 5.1 provides a template
and/or worked example, plus the types it names without a format (§3). PDF page
numbers are in `source/dfi-5.1/SOURCE.md`.

**Priority key.** **P1** = foundation and highest staff use (build first; proves
the shared engine). **P2** = common staff products that reuse P1 components.
**P3** = specialist or ministerial products with forms and boxed layouts.
**P4** = publications and low-frequency products.

**Scheme key** (paragraph numbering, see `standards/03`): **C** = correspondence,
**D** = directive (hanging), **P** = publication, **–** = none or tabular.

## 2. Detail by document type

Each entry lists **mandatory structural elements** (in DFI order) and **unique
formatting requirements**, meaning those that differ from or add to the shared
standards. Shared rules (page setup, fonts, markings, signature-block variants,
supporting documents) are not repeated here. `SB-*` refers to the signature
block variants in `standards/04` §2.

### 1. Minute (2D / 2C)
- **Structure:** markings → originator descriptor → identifier
  "[Appointment] MINUTE [nn/yyyy]" → date + file reference line → action
  addressee "(through …)" → For information + addressees → SUBJECT HEADING →
  Reference (optional) → Purpose (recommended) → body (main and group headings
  optional) → Recommendations (if a decision is sought) → signature block
  (SB-MINUTE) → DTelN → Annex(es) → Enclosure(s) → Distribution.
- **Unique:** descriptor is the first line, centred and bold ([A-22]); date is
  dd Mmm yy with the day handwritten ([A-01], [A-02], [A-06]); at most six
  information addressees; with more, a distribution list may be used ([A-04]); no badge or
  logo; pages numbered only when there are two or more; footnotes for
  non-principal references; no hyperlinks; a single approval may use an
  "approved / not approved" statement above the signature (2.1.11(13)).

### 2. Submission (2F / 2E)
- **Structure:** as Minute, with a fixed body: **Purpose** group heading →
  1. Issue. → 2. Recommendation(s). (with a/b/c note/agree list) → 3. Timing.
  (omit if not relevant) → **Context** group heading (sub-paragraphs Content,
  Sections, Argument, Implications, Effects, Consultation) → a paragraph headed
  **Financial and resource implications.** (mandatory; if there are none, say
  so: 2.1.12b(3)) →
  **Summary** (optional, no new information) → SB-MINUTE → DTelN → Annex(es) →
  Enclosure(s).
- **Unique:** there **should** be only one addressee (the decision-maker, 2.1.11(6)); information
  addressees only if essential; ideally no more than four pages.
  The templates 2E/2F do not show the Financial and resource implications
  paragraph that the prose requires: see [A-34].

### 3. Annex / appendix pages (shared)
- **Structure:** markings → right-aligned bold identifying block (ANNEX X /
  unique identifier / date) → subject heading → body → page numbers A-1 or
  A-1-1.
- **Unique:** see `standards/05`; [A-12].

### 4. Dot-point brief (2O)
- **Structure:** markings → date + file reference → "DOT-POINT BRIEF FOR
  [APPOINTMENT]" → SUBJECT HEADING → Purpose (numbered) → group-headed
  numbered paragraphs with bullets → SB (name / title-rank / organisation) →
  DTelN → Enclosure(s) → Flags → Commands, departments and authorities
  consulted.
- **Unique:** right margin may be 4 cm; bullets wrap at 2 cm; bullet spacing
  6/3 pt; does **not** seek a decision; consultation is listed below the
  signature block.

### 5. Visit report / PAR (2Q / 2P)
- **Structure:** markings → date + file reference (right) → action addressee
  (through) → For information / See distribution → subject heading beginning
  "VISIT REPORT –" or "POST ACTIVITY REPORT –" → Introduction (date, time,
  location, purpose, participants) → Visit report (content) → Decisions
  (Agreement / For action / For information / Further action) → Background
  information → Conclusion(s) (optional) → Recommendation(s) (optional) →
  SB-MINUTE → DTelN → **Annex A: Summary of travel details (mandatory)** →
  Enclosure(s) → Distribution.
- **Unique:** plain paper, no device; classified no lower than the activity;
  signed by the senior member; submit within about two weeks; Annex A has a
  fixed travel-cost table (Event, Dates, Expense | Details | Cost (NZ$), with
  the rows in Fig 2-19 p3).

### 6. Internal formal (demi-official) letter (2H / 2G)
- **Structure:** badge/logo (top left) + unit name and address (top right) →
  optional "From: [appointment or name]" centred → file reference (right, if
  required) → full date (left) → recipient name / appointment / unit → salutation
  (typed or handwritten) → SUBJECT HEADING (optional) → unnumbered paragraphs →
  complimentary close → SB-LETTER.
- **Unique:** single named addressee; no paragraph numbers or bullets; no
  annexes (enclosures allowed); first-person singular (plural where a wider
  opinion is reflected); full date; 24-hour clock;
  avoid Service abbreviations; two variants (typed vs handwritten salutation
  and close); admonition letters have no salutation or close; device per the
  identity matrix ([A-14]); [A-15].

### 7. External letter (2J / 2I)
- **Structure:** badge/logo + sender address → optional From line → full date
  ([A-30]) → recipient address block → salutation → SUBJECT HEADING (optional)
  → unnumbered paragraphs (the reference goes in the opening paragraph:
  "Thank you for your letter of …") → close → SB-LETTER.
- **Unique:** no file reference; **12-hour clock**; no paragraph numbers or
  bullets; salutation and close rules per 2.1.18; signatory limited to CDF,
  COS, or a delegated senior commander or executive; no annexes; plain
  language, no jargon.

### 8. Administrative Instruction (3F)
- **Structure:** markings → ORIGINATING HQ/BRANCH (centred, upper case) →
  [Originator] → date + file reference → See distribution →
  "[AUTHORISED APPOINTMENT] ADMINISTRATIVE INSTRUCTION [NN/YYYY]" → SUBJECT
  HEADING → Authority → Applicability (verbatim boilerplate) → Purpose →
  Introduction → Conduct → Tasks → Coordinating arrangements → Administration
  (Finance, Legal) → Command and control (Reporting, DIRLAUTH, Points of contact)
  → Cancellation (with an effective date) → SB → Annex(es) → Enclosure(s) →
  Distribution.
- **Unique:** **no badges, crests or logos**; distribution list if more than
  four addressees; identifier bold upper case immediately above the subject;
  hanging first-level paragraphs (scheme D); mandatory language; em-dash list
  lead-ins; signed and dated by a delegated authority.

### 9. CDF Directive (3D)
- **Structure:** markings → NZDF assented badge + address line → date →
  addressee / See distribution → "CDF DIRECTIVE [NN/YYYY]" → SUBJECT HEADING →
  Authority ("Issued by the Chief of Defence Force.") → Applicability (verbatim,
  3 paragraphs) → Purpose → Context/Situation → Conduct → Accountabilities and
  responsibilities → Coordinating arrangements → Administration (Finance,
  Legal) → Command and control (Reporting, DIRLAUTH, Points of contact) →
  Cancellation and disposal instructions → SB (CDF) → Annex(es) →
  Enclosure(s) → Distribution.
- **Unique:** **all pages numbered, including page 1**, when there are two or
  more; number issued by OCDF; more than four addressees means a distribution
  list; annexes only in exceptional circumstances; no bullets; valid for no
  more than one year; never amended (cancel and reissue). Variants: COS and
  commander directives (Service badge optional, 3.2.12) and senior-executive
  directives (**no badge**, 3.2.13).

### 10. NZDF Note (Submission) to the Minister (2AC)
- **Structure:** markings (minimum IN-CONFIDENCE) → NZDF badge + HQNZDF address
  block (right) → month and year (right margin) → "Minister of Defence" →
  SUBJECT (topic) → Purpose ("The purpose of this Note is to …") → content
  heading(s) → Additional Requirements (Ministerial Referral, Filing) →
  Recommendations ("It is recommended that the Minister:" note/agree list) →
  SB (CDF) → Annex(es) → Enclosure(s) → Ministerial referral line.
- **Unique:** IN-CONFIDENCE on every page; single-page notes not numbered;
  multi-page notes numbered from page 2; no abbreviations in the subject heading
  (2.3.8(7)) and no acronyms anywhere unless the Minister prefers them (2.3.6a); recommendations must stand alone; filed with the QA form and
  cover sheet as one document; [A-16], [A-17].

### 11. NZDF Submission to the Minister cover sheet (2AB)
- **Structure (one-page table):** NEW ZEALAND DEFENCE FORCE / SUBMISSION TO
  MINISTER COVER SHEET → Title → Tracking No. (NZDF; Minister's) → Importance
  (High / Moderate / Routine checkboxes, colour-filled) → Urgency → Request
  ministerial response by → Contacts (name, Tel, A/H) → Purpose (no more than
  six lines) → Recommendations (no more than six lines) → MoD/NZDF Consultation
  → Minister's Comments → Minister's Action (Signed / Noted / Agreed / Approved
  / Declined / Discussion required; Referred to) → Minister's Signature, Date →
  SB (CDF) + Date.
- **Unique:** must not exceed one page; shaded cells; importance colours
  red/orange/green ([A-24]); footnotes 1–3 as printed ([A-17]).

### 12. NZDF Quality Assurance Form (1B = 2AG)
- **Structure:** HQNZDF / Quality Assurance Form header → Title → Document type
  checkboxes (12 types) → Purpose → Deadline for approval (CDF / OMINDEF /
  Other) → endorsement rows (CPO Portfolio, Finance Branch, DLS, Other ×2:
  Name, Contact, Date) → Consultation → Services/Portfolio approval → Document
  Owner/Author QA completed → Cleared through Ministerial Services → Chief of
  Staff HQNZDF → page 2 notes (verbatim, including the sign-off process
  graphic).
- **Unique:** form layout; a one-page form (the notes are page 2); [A-35] for
  the sign-off process graphic, which is an image.

### 13. Briefing Note to the Minister (2AF / 2AE)
- **Structure:** markings → NZDF badge + "BRIEFING NOTE to the MINISTER OF
  DEFENCE (Minister for Veterans)" → table: Title, Tracking No., Importance,
  Urgency, Contact → numbered paragraphs inside the table, ending "It is
  recommended that the Minister: a. **note** …" → Minister's Comments →
  Minister's Action (template 2AF: signed / noted / agreed / approved /
  declined / discussion required; example 2AE: Noted / Discussion required) →
  Minister's Signature, Date
  → SB (CDF) → date.
- **Unique:** **one page**; noting brief only, no decision sought; the date
  position differs between example and template ([A-19]).

### 14. Correspondence to the Minister for Veterans (2AD)
- **Structure:** as item 10, addressed to the Minister for Veterans, HQNZDF
  address block left.
- **Unique:** NZDF badge top left and Veterans' Affairs logo top right
  (2.3.8(3)); the template omits the logo and uses "Minister of Veterans"
  ([A-18]).

### 15. Joint Note (Submission) to the Minister (2Z / 2Y)
- **Structure:** markings (minimum IN-CONFIDENCE) → "OFFICE OF THE CHIEF
  EXECUTIVES / CHIEF OF DEFENCE FORCE - SECRETARY OF DEFENCE / Defence House,
  Wellington, New Zealand" with the NZDF badge and MoD coat of arms → date
  (month and year, right) → Minister of Defence → SUBJECT → Purpose → content →
  Additional Requirements → Recommendations → **SB-JOINT (CDF left, SecDef
  right)** → Annex(es) → Enclosure(s) → Ministerial referral.
- **Unique:** must be signed by **both** chief executives; one addressee.

### 16. Joint Submission cover sheet (2X)
- As item 11, with the Office of the Chief Executives header, MoD and NZDF file
  numbers, and SB-JOINT with dates.

### 17. Joint Quality Assurance Form (2AA)
- **Structure:** NZDF and MoD Correspondence QA Form → Urgent / Not Urgent →
  title → document type checkboxes (Weekly report, NTM, Ministerial, OIA/Privacy
  Act, PQ, Request for information) → Author / Peer Review / Branch Head /
  CFO / Other approval rows (Position, Signature, Date) → Consultation
  (Internal, External, Ministerial Services QA, Comments) → For OCDF/MoD
  Corporate Services use only.
- **Unique:** form; excludes Cabinet papers.

### 18. Delegation (temporary) (2L / 2K)
- **Structure:** markings → address block (right) → date (Mmm YY) → addressee
  name / position → [SUBJECT LINE] ([A-20]) → DELEGATION OF AUTHORITY → paras
  1–2 (absence and statutory basis, verbatim) → Delegation → Exceptions to
  delegation → SB-FORMAL.
- **Unique:** boilerplate statutory wording (s 30(2) Defence Act 1990, s 2
  AFDA); em-dash list lead-ins although this is an administrative document
  ([A-07]); hanging paragraphs ([A-05]); CDF delegations may carry the badge
  (2.2.3(2)).

### 19. Delegation (permanent) (2N / 2M)
- **Structure:** markings → address → date → NAME / rank-position of the
  delegate → DELEGATION → [DELEGATION DESCRIPTION] → Delegation → Exceptions to
  delegation → Accountability → Special instructions → Revocation and
  consequential amendments to publications → Cancellation instructions →
  SB-FORMAL.
- **Unique:** as item 18; the example contains numbering errors (E-03).

### 20. Meeting agenda (2S / 2R)
- **Structure (A4 landscape, table):** markings → [COMMITTEE NAME] / AGENDA
  with a Date / Time / Venue / Reference block → Members | In Attendance |
  Apologies row → Time | Item | Discussion Notes | Lead table, with fixed first
  items (Open meeting; Minutes of the last meeting; Matters arising) and fixed
  last items (Any other business; Arrangements for the next meeting /
  Closing) → SB-CHAIR with date.
- **Unique:** **landscape**; no badges; topic-level grading "(R) Subject";
  times hhmm-hhmm. The example and template differ in their last item ("Closing"
  vs "Arrangements for the next meeting"; prose 2.2.14(2) uses the latter).

### 21. Minutes of a meeting (2U / 2T)
- **Structure (portrait, table):** markings → [COMMITTEE NAME] / MINUTES with
  Date / Time / Venue / Reference → Members | In Attendance | Apologies →
  Topic/Discussion | Outcomes/Decisions/Action Items rows → SB-CHAIR with date.
- **Unique:** reported speech; attendees in order of precedence (alphabetical
  where equivalent); representatives shown with the person represented;
  apologies listed; per-topic grading; each decision states who, what, when and
  how; draft issued within five working days; signed by the chair after
  approval at the next meeting. An action-item list is optional and has no set
  format.

### 22. DFO (Temporary): conditions of service (3C / 3B)
- **Structure:** markings → address → date → "DFO(T) [nn/yyyy]" → CONDITIONS OF
  SERVICE → [SERVICE NUMBER AND NAME]; [POST TITLE] → Authority (s 27 and 45) →
  Purpose → Special Conditions of Service → Responsibilities → Cancellation →
  SB-FORMAL.
- **Unique:** number from OCDF; need-to-know privacy markings (for example
  STAFF-IN-CONFIDENCE in 3B); a cancellation date is required (generally
  within one year); the template contains drafting errors (E-04, E-05).

### 23. DFO (Temporary): officers' appointments (3A)
- **Structure:** markings → address → Service crest or badge → date →
  "DFO(T) nn/YYYY [Service]" → APPOINTMENT, PROMOTION, AND DISCHARGE OF OFFICERS
  → Authority → Orders → Releasability (paras 3–5 verbatim) → SB-FORMAL (Chief
  of Service) → Annex A list of appointments.
- **Unique:** issued by a COS under delegation; example only, no template.

### 24. CDF Operational Directive (3E)
- **Structure:** markings → NZDF badge + address → Copy n of N → date →
  COMJFNZ → For information / See distribution → "CDF OPERATIONAL DIRECTIVE
  [NN/YYYY]" → "OPERATION [NAME]" → Authority → Situation → Mission →
  Execution (Intent, Tasks) → Coordinating instructions (minimum: command and
  control, locations, timings, planning guidance, freedoms and constraints) →
  Logistics and administration (minimum five elements) → Command and control
  (minimum four elements) → Acknowledgement → Cancellation instructions
  (optional) → SB (CDF) → Annex(es) → Enclosure(s) → Distribution.
- **Unique:** addressed to COMJFNZ; all pages numbered, including page 1; numbers
  controlled by AC SCE; tasks phrased "you are to / BPT / on order"; copy-number
  placement ([A-21]); FRAGO format set by AC SCE (out of scope).

### 25–26. DFI/DM and DFO publications (4A–4G)
- **Structure:** cover/title page (marking, type and number, title, release
  statement, copyright, issuing authority block) → Authority Order (Authority,
  Conflict, SB-AUTHORITY) → Foreword (optional) → Contents (auto TOC) →
  Preliminary Provisions (fixed headings and boilerplate) + Annex A Meanings of
  Terms → main content (parts / chapters / sections, Heading 1–5, scheme P,
  annex lists per part or chapter) → End Matter (Record of Change, Schedules).
- **Unique:** see `standards/08` (margins top 3 cm, running header with title,
  version, part and date, four page-numbering regimes, warnings/cautions/notes,
  revision bars, amendment numbering).

### 27. Publications QA Form (4H)
- One-page form: short and long title; Secondary Legislation / NZDF Policy
  checkboxes; Category; Custodian; Scope; Consultation; Consequential changes;
  DLS consent; Approving Authority approval; footnotes 1–3 verbatim.

### 28. Memorandum of Understanding (2V)
- **Structure:** cover page (MEMORANDUM OF UNDERSTANDING / Between the New
  Zealand Defence Force and [organisation] / date) → "THIS MEMORANDUM OF
  UNDERSTANDING is made on…" BETWEEN / AND → Introduction → Definitions →
  Provision of support to operations and training (centred main heading) →
  Requests for support → Sharing of information → Implementing arrangements →
  Differences → Costs → Effective date, variation, review and termination →
  Participants' representatives table → SIGNED at … with two signature columns
  ("Dated this [dd] day of [MMM yyyy]") → List of annexes.
- **Unique:** centred main headings used as section dividers; clauses numbered
  continuously; dual signature lines; DLS may prescribe a different format;
  third-party MOUs follow the principal's format; boilerplate references the
  repealed Privacy Act 1993 (E-06).

### 29. Professional literature: preliminary page (2W)
- **Structure:** [Name of publication] → descriptive paragraphs → Abstract →
  Disclaimer → Release → Copyright (verbatim) → imagery attribution.
- **Unique:** the body of professional literature follows the **Chicago Manual
  of Style**, not DFI layout (2.2.25b). This repository will only produce the
  preliminary page. The disclaimer text in 2W is garbled (E-07).

### 30. Generic non-letter layout (1A)
This is reference material, not a product. It is the most complete single
statement of the correspondence layout and is used as the first visual
regression target for the shared engine.

### 31. Email (2A / 2B)
Not a `.docx` product. The repository may later provide a text or HTML snippet
generator and a lint (subject-line markings, "UNCLASSIFIED" for external email,
Calibri 11, no hyperlinks or images for overseas military recipients, approved
signature block). It is not a template.
