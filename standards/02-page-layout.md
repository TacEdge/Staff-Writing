## 4. Headers and footers (1.2.18)

| Rule | Tag | Cite |
|---|---|---|
| Header: security classification, then any endorsement marking, centred, bold, upper case. The classification is on the **first line**. | [M] | 1.2.16(5), 1.2.18a, c |
| Footer: page number, then endorsement marking, then security classification. The classification is on the **last line** (mirror order). | [M] | 1.2.16(5), 1.2.18b, c; Figs 1-4, 2-3 |
| Endorsement markings sit *inside* the security classification (between it and the body). Privacy markings are treated as endorsement markings. | [M] | 1.2.16(5), fn 25 |
| The header contains no badge or logo. Where a badge is authorised, it is applied immediately below the header, in line with the address block. **Conflicts with 2.1.16(3) for letters: see [A-14].** | [M] | 1.2.18a |
| If the document is unclassified and does not refer to a classified document, no "UNCLASSIFIED" marking is required. See [A-38] for publications and Ministerial documents. | [M] | fn 24 |
| Publications have their own header content (long title, version, part/chapter, date). | [M] | 4.4.8; see 08 |

## 5. Page numbering

| Case | Rule | Tag | Cite |
|---|---|---|---|
| Unclassified / Restricted, main document | Consecutive non-bold Arabic numerals, centred in the footer, **above** any protective marking. **The first page is not numbered.** | [M] | 1.2.16(6) |
| Minutes (Unclassified/Restricted) | Numbered only when there are two or more pages | [M] | 2.1.11(18) |
| Formal letters | Numbered if more than one page, or if any marking, code word or caveat is applied | [M] | 2.1.16(19) |
| Notes to the Minister | Single page not numbered. Multi-page notes are numbered from the second page. | [M] | 2.3.8(4) |
| CDF Directives, CDF Operational Directives | All pages numbered **including the first**, when there are two or more pages | [M] | 3.2.11(1), 3.2.18(1) |
| Classified above Restricted | "Page n of N", centred, in sentence case, immediately above the classification. The first page shows the total. N includes annexes, appendices and enclosures (which are not numbered separately). A single page is "Page 1 of 1". | [M] | 1.2.16(7) |
| Correspondence annexes | Multi-page annexes: A-1, A-2. Single-page annex: not numbered. Above Restricted: per DFO 51 (not held; see [A-31]). | [M] | 1.2.24(1)(f); Fig 1-5 |
| Correspondence appendices | A-1-1 (annex, appendix, page). Single-page appendix not numbered. | [M] | 1.2.24(2)(c); Fig 1-6 |
| Publications | Roman / Arabic / part-page / EM- schemes | [M] | 4.4.7b–c; see 08 |

Templates disagree on how page 1 is shown (for example the AI template shows
"(Page 1 of 2)" on an unmarked template). See [A-11].

## 6. Copy numbers (1.2.16(9), 1.2.18)

- Every copy of a classified document that needs distribution control carries an
  individual copy number on its **first page**. [M]
- Position: 1.2.16(9) says right-aligned in the header, on the line below any
  protective markings, in sentence case: "Copy 1 of 20". [M] But 1.2.18c says
  "appended immediately below the header", Fig 1-4 shows it right-aligned in the
  body below the letterhead/crest, and Fig 3-6 shows it at the left above the
  date. See [A-21].
- Fig 1-4 fn 2 limits copy numbers to documents classified above Restricted. [T]
- A copy distribution list headed **Copy Distribution** (bold) goes after any
  annexes, enclosures and distribution addressees, and shows the full
  distribution of all numbered copies. [M]

## 8. Hyperlinks (1.2.20, Table 1-1)

- Calibri, underlined, RGB (0, 0, 255). Titles of complete works are also in
  italics. [M]
- Allowed in emails and online publications. **Not used in minutes or
  letters.** [M] Table 1-1
- Remove hyperlinks and embedded images from emails to overseas military
  addressees. [D] 2.1.6c note
- Online reports in the DIE: internal hyperlinks only. External NZDF website
  publications: no DIE hyperlinks. [M] 2.2.25c, 4.2.3c

## 9. Electronic delivery

- Final electronic correspondence should be PDF where possible, with security
  set so the text cannot be altered. [D]/[M] 1.1.3d(8)
- In the final version, annexes, appendices and enclosures are part of **one**
  Word file, not separate files. [M] 1.2.24(6)
- When using a template, use "save as", not "open". [D] 1.2.3g(8)
- Ministerial drafts go to Ministerial Services as MS Word by email. [M] 2.3.6d
